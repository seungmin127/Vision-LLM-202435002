# 궁그미 - 촉각 탐색 기반 AI 음성 학습 도우미

선천적 시각장애 아동이 물건을 탐색하고 발견한 특징을 말하면 질문과 설명으로 대화를 이어 가도록 지원하는 프로젝트입니다.
물체의 이름을 먼저 알려 주기보다 아이가 특징과 경험을 말할 기회를 통해 학습을 이어나가는 것이 목표입니다.

## 파일 구조 (필수)

```text
Project03/
├── main.py             # 실행, 공유 정보, 보호자 화면, 종료와 기록 저장
├── vision.py           # YOLO, 손끝 추적, 물건 선택
├── conversation.py     # 녹음, Whisper, Gemma, Piper, 최근 대화
├── settings.py         # 기존 설정 + YOLO_DEVICE
├── models/             # 기존 모델을 원래 하위 경로대로 배치
├── tools/              # 기존 Whisper 실행 파일을 원래 하위 경로대로 배치
├── runtime/            # 임시 WAV와 Whisper/aplay 로그
└── sessions/           # 정상 종료 시 대화 기록 JSON
```

- **main.py**: 파일 확인, 공유 정보와 카메라 스레드 생성, 보호자 화면 출력, 종료 및 기록 저장을 담당합니다.
- **vision.py**: YOLO11n 탐지, MediaPipe 손끝 추적, 손끝과 바운딩 박스의 거리 계산과 학습 대상 선택을 담당합니다.
- **conversation.py**: 자동 녹음, Whisper CLI, Gemma 대화 생성, Piper 합성과 aplay 재생, 최근 대화 및 조작 명령을 담당합니다.
- **settings.py**: 모델·실행 파일 경로, 카메라 파이프라인, CPU·GPU 설정, 녹음 조건, COCO 한국어 이름·접촉 구분과 SYSTEM_PROMPT를 보관합니다.
- **models/, tools/**: 모델과 Whisper 실행 파일의 기본 배치 위치입니다. 기존 파일이 다른 위치에 있으면 settings.py의 경로를 수정합니다.
- **runtime/**: 처리 중 임시 WAV와 Whisper·aplay 로그를 저장합니다. 입력 음성·응답·신호음 WAV는 처리 후 삭제합니다.
- **sessions/**: 종료할 때 전체 대화 텍스트를 JSON으로 저장합니다. 다음 실행에서 자동으로 다시 불러오지는 않습니다.

## 실행 방식 (필수)

### 실행 환경

Jetson의 기존 실습용 Python 가상환경, USB 카메라, 기본 마이크·스피커를 사용합니다.
필요한 패키지는 numpy, GStreamer 지원 OpenCV, torch/torchvision, ultralytics, mediapipe,
sounddevice, llama-cpp-python, piper-tts이며 Whisper CLI와 ALSA aplay도 필요합니다.

### 실행 명령

기존 Jetson 실습 환경에서 `Project03` 폴더로 이동한 뒤 실행합니다.

```bash
python3 main.py
```

모델과 실행 파일은 압축 파일에 포함하지 않았으며 새로 다운로드하지 않았습니다.
기본 설정은 다음 상대 경로를 사용합니다. 이미 다른 위치에 파일이 있다면 파일을 옮기는 대신 settings.py에서 각 경로를 실제 위치로 지정해도 됩니다.

```text
models/yolo11n.pt
models/hand_landmarker.task
models/google_gemma-4-E2B-it-Q4_K_M.gguf
models/speech/ggml-small.bin
models/speech/ko_KR-kss-medium.onnx
models/speech/ko_KR-kss-medium.onnx.json
tools/whisper/build/bin/whisper-cli
```

기존 Python 패키지와 GStreamer 지원 OpenCV, 기본 마이크, ALSA `aplay`를 사용합니다.

### 경로와 장치 설정

- 모델을 YOLO·MediaPipe·Gemma4·Piper 등 종류별 폴더에 보관하면 각 모델 경로에 해당 하위 폴더까지 포함해야 합니다.
- 외부 whisper.cpp를 사용하면 WHISPER_MODEL과 WHISPER_PROGRAM을 각각 실제 모델·실행 파일 경로로 수정합니다. build/bin과 build-cpu/bin 중 실제 whisper-cli가 있는 위치를 사용합니다.
- Whisper 기본 모델은 한국어를 지원하는 base입니다. 
- CAMERA_PIPELINE의 기본 입력은 /dev/video0, YUY2, 640×480, 30FPS입니다. 실제 장치와 지원 형식에 맞춰 지정하고 다른 카메라 프로그램을 종료한 뒤 실행합니다.
- YOLO_DEVICE="0"은 CUDA GPU, "cpu"는 CPU 실행입니다. 기본 GPU 설정에서 CUDA를 사용할 수 없으면 오류를 알립니다.
- GPU_LAYERS=-1은 Gemma GPU 오프로딩을 요청하고, 0은 Gemma CPU 실행입니다. Whisper는 -ng로 CPU 추론을 요청하고 Piper도 CPU를 사용합니다.
- HEADLESS=False는 보호자 창 표시, True는 창만 생략하는 음성 전용 모드입니다. True여도 카메라 처리는 유지됩니다.

### 사용 순서와 종료

모델 준비와 시작 인사 후 물건을 카메라에 보여 줍니다. 대상이 선택돼 첫 질문이 출력되면 신호음 뒤에 말합니다.
카메라의 물체 선택과 별도로 음성은 녹음 → Whisper → Gemma → Piper 순서로 처리됩니다.

첫 질문에 대해 사용자가 답변을 하면 Gemma를 통해 추가적인 질문을 받게 됩니다. 따라서 양방향 소통으로 대화를 계속적으로 진행되고 새로운 객체가 감지된다면 이전 감지된 물체에 대한 정보는 잃어 버리고 새로운 물체에 대해서 대화를 이어가게 됩니다. 

| 대표 음성 명령 | 동작 |
| --- | --- |
| 궁그미 종료 / 그만 | 작별 인사 후 종료 |
| 새 물체야 | 현재 후보 또는 저장된 대상으로 새 대화 시작 |
| 같은 물체야 | 전환 후보를 해제하고 해당 발화를 대화에 전달 |
| 다시 말해줘 | 마지막으로 완료 재생된 문장 다시 재생 |

콘솔에 마이크 대기, 음성 감지, 녹음 완료, Whisper 인식 결과, Gemma 입력과 생성 답변을 구분해 표시합니다.
시작 인사·첫 질문·종료 인사·오류 안내는 고정 문장이며 일반 대화 생성 결과와 구분합니다.

## 창의성 및 확장성

### 아이디어 설명

물체 이름을 바로 알려 주는 기능보다 아이가 직접 만지고 발견한 특징을 말하는 탐색 경험을 통해 아동이 자기주도적으로 학습을 진행하는 것에 초점을 맞췄습니다.
만약 부모가 부재 상황 등 여러 상황에서 물체 종류, 아이의 발화와 최근 대화를 연결해 질문과 설명을 이어 가는 것이 핵심 아이디어입니다.

### 구현한 내용

- YOLO11n, 전체 COCO 80종 검출·표시, 검출 신뢰도 0.35와 학습 후보 신뢰도 0.50.
- 학습 후보에서 `person`, `dining table` 제외.
- MediaPipe HandLandmarker VIDEO 모드와 손끝 번호 4·8·12·16·20.
- 손끝에서 바운딩 박스까지 32픽셀 이내의 가장 가까운 후보 선택. 같은 거리면 선택 보류.
- 후보 하나면 손이 없어도 선택. 약 2초 동안 유지되는 후보로 학습 시작.
- 가려진 대상과 대화 유지. 다른 종류가 안정적으로 선택되면 새 대화 시작.
- Whisper base, 한국어, CLI, CPU `-ng`, 음성 크기·무음 기반 자동 녹음.
- Piper KSS 1회 로딩, WAV 합성 후 기본 출력으로 `aplay` 재생, 반이중 대화와 신호음.
- Gemma GGUF, `Llama`, `GPU_LAYERS`, `create_chat_completion()`과 최근 대화 기록.
- 교육·안전 관련 SYSTEM_PROMPT를 사용하고 단순 반복을 줄이는 지침을 추가. Gemma에는 영상 대신 종류·신뢰도·검출 여부·접촉 구분과 최근 대화를 텍스트로 전달.
- 종료·새 물체·같은 물체·다시 말하기 명령. 일반 질문의 뜻은 Gemma가 판단.
- 입력 녹음·응답 WAV 삭제, Whisper/aplay 중단 및 회수, 카메라·MediaPipe·Gemma 정리.
- OpenCV는 카메라 입력, BGR→RGB 변환, 손 관절·상태 표시와 보호자 화면 출력에 사용합니다.

### 온디바이스 환경에 적합한 이유

네트워크 연결 의존도를 줄여 외부와 네트워크가 끊긴 상황에서도 센서 입력과 AI 음성 대화를 하나의 기기에서 연결할 수 있습니다.

### 확장성

- **학습 대상 확대**: 교구·도형·장난감 등 필요한 물체를 추가 학습해 인식 범위를 확장할 수 있습니다.
- **개인별 대화 설정**: 보호자가 선택한 학습 수준과 말하기 속도에 따라 질문 난이도, 설명 길이와 대기 시간을 조정할 수 있습니다.
- **보호자 연계**: 동의하에 보관한 탐색·대화 기록을 검토하고 다음 학습 활동을 준비하는 기능으로 확장할 수 있습니다.

## 기타 참고 사항

### 작업 중 경험한 문제와 대응

- **모델 경로 오류**: 코드 폴더와 모델 보관 폴더가 달라 실제 파일 위치에 맞춰 설정하는 작업을 진행했습니다.
- **카메라 입력 실패**: 장치 식별·파이프라인 생성 실패 로그를 확인하고 정상 실행 코드와 카메라 설정을 비교하도록 했습니다.
- **화면 응답 지연**: 모델 로딩·네이티브 연산 중 메인 화면 갱신이 지연될 수 있어 HEADLESS 모드로 분리 점검하도록 했습니다.
- **음성 인식 여부 불명확**: 녹음 감지, Whisper 결과와 Gemma 입력·출력에 단계별 콘솔 표시를 추가했습니다.
- **반복 답변**: 발화를 단순 반복하지 말라는 지침을 추가했습니다.

### AI 활용 및 본인 기여도

**AI 활용**

- AI 활용해 실습 코드·요구사항 정리와 코드 초안 작성·리팩토링을 지원받았습니다.
- 함수 분리, 공유 데이터 관리, 음성·대화 연결과 주석 작성을 지원받았습니다.
- 오류 로그 해석, 수정 후보 검토, 정적·모의 검사와 발표·문서 작성을 지원받았습니다.

**본인 기여**

- 프로젝트 주제와 촉각 탐색 중심의 학습 흐름, 필요한 기능과 단순화 방향을 결정했습니다.
- 실습 코드 재사용과 Jetson 카메라 파이프라인, Whisper CPU 실행 등의 조건을 정했습니다.
- Jetson에서 파일을 배치하고 라이브러리·모델 경로 및 입력 장치를 확인하며 실행했습니다.
- 카메라·음성 인식·응답 문제를 직접 확인하고 로그와 화면을 바탕으로 반복 수정 과정을 진행했습니다.
- 시연과 발표 자료를 준비했습니다.
