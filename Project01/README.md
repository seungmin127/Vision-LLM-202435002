# 손동작 인식 기반 가상 메모장

## 1. 프로젝트 소개

OpenCV와 MediaPipe를 활용하여 카메라로 초록색 펜과 손동작을 인식하고 별도의 태블릿이나 터치스크린 없이 가상 메모장에 글씨를 작성하는 프로젝트이다.

펜촉 위치를 추적하여 그림을 그리고 손가락의 펼침 상태에 따라 그리기, 지우기, 저장 및 종료 기능을 수행한다.

## 2. 파일 구조

```text
Hand-Memo-Board/
├── hand_memo.py
├── hand_landmarker.task
├── memos/
│   └── memo_YYYYMMDD_HHMMSS_ffffff.png
└── README.md
```

- hand_memo.py: 카메라 입력, 영상 전처리, 펜촉 검출, 손동작 인식, 칼만 필터, 메모장 제어 및 저장 기능을 구현한 메인 코드
- hand_landmarker.task: MediaPipe 손 관절 검출을 위한 사전 학습 모델
- memos/: 작성한 메모 이미지가 PNG 형식으로 저장되는 폴더
- README.md: 프로젝트 소개 및 실행 방법

## 3. 실행 방식

### 3.1. 실행 환경

- Python
- OpenCV (GStreamer 지원 환경)
- NumPy
- MediaPipe
- USB 카메라
- Linux 기반 카메라 환경 (`/dev/video0`)

### 3.2. 필요 라이브러리 설치

```bash
pip install numpy mediapipe opencv-python
```

### 3.3. 프로그램 실행

`hand_memo.py`와 `hand_landmarker.task` 파일을 같은 폴더에 배치한다.

```bash
python hand_memo.py
```

프로그램 실행 후 USB 카메라에서 실시간 영상을 입력받으며 카메라 화면과 가상 메모장이 하나의 창에 표시된다.

### 3.4. 손동작별 기능

1. 펜을 쥔 기본 자세 -> DRAW : 펜촉을 이동하여 초록색 선 그리기
2. 새끼손가락 펼치기 -> ERASE : 펜촉 주변의 그림 지우기
3. 다섯 손가락 모두 펼치기 -> SAVE_EXIT : 1초 유지 시 PNG 저장 후 종료
4. 기타 자세 또는 펜촉 미검출 -> PAUSE : 그리기 및 지우기 중지

- `Q` 또는 `ESC`: 저장하지 않고 프로그램 종료
- 저장 위치: `memos/` 폴더

## 4. 창의성 및 확장성 

### 4.1. 아이디어 설명

기존의 메모 프로그램은 마우스, 키보드, 터치스크린 등의 입력 장치를 사용했지만 본 프로젝트애소눈 이러한 입력 장치 대신 **실제 펜과 손가락 동작을 활용하는 비접촉식 메모 시스템**을 구현하는 것을 목표로 하였다.

특히 펜촉의 위치는 영상처리 기술로 검출하고, 그리기와 지우기 등의 명령은 손가락 동작으로 구분하여 구현하고자 하였다.

### 4.2. 구현한 내용

영상 전처리 및 초록색 펜 검출
- LAB 색공간과 CLAHE를 이용한 밝기 대비 보정
- Gaussian Blur를 이용한 영상 잡음 완화
- HSV 색공간에서 파란색 영역 분리
- 모폴로지 Opening 및 Closing을 통한 마스크 개선
- 윤곽선 및 이미지 모멘트를 이용한 펜 중심점 계산
- Canny Edge와 직선 피팅을 활용한 펜촉 후보 검출

칼만 필터 기반 펜촉 위치 보정
- 측정값과 예측값을 결합하여 펜촉 좌표의 흔들림 완화

MediaPipe 기반 손동작 인식
- 손의 21개 랜드마크 검출
- 손가락 펼침 상태에 따른 그리기, 지우기, 저장 동작 분류

가상 메모장 구현
- 이전 펜촉 좌표와 현재 좌표를 연결하여 선 그리기
- 손을 펼친 상태를 1초간 유지하면 PNG 이미지 저장 후 종료

### 4.3. 창의적인 요소

**손동작을 이용한 모드 전환**

별도의 키보드나 버튼 조작 없이 손가락 자세만으로 그리기, 지우기, 저장 기능을 제어하도록 구현하였다.

**영상처리와 손동작 인식의 결합**

OpenCV를 이용한 펜 위치 검출과 MediaPipe를 이용한 손동작 분석을 결합하여 위치 입력과 기능 선택을 동시에 수행하도록 구성하였다.

**오작동 방지**

펜촉이 검출되지 않거나 손동작이 명확하지 않을 경우 그리기를 중단하도록 했으며 저장 동작은 1초 이상 유지해야 실행되도록 하였다.

### 4.4. 향후 확장성

- 다양한 색상의 펜을 인식하여 글씨 색상 변경
- 손동작을 추가하여 실행 취소(Undo) 기능 구현
- 펜촉 검출 정확도 개선 및 추적 안정화
- 필기 데이터를 활용한 손글씨 인식 기능 추가

## 5. 기타 참고 사항 (과제 & 프로젝트)

### 5.1. 구현 과정의 주요 고려사항

**펜촉 위치 검출**
초록색 펜 몸통은 HSV 마스크를 이용해 검출할 수 있지만 실제 펜촉은 초록색 영역 밖에 있는 것을 고려하여 윤곽선의 중심축과 Canny Edge를 함께 활용하도록 구성하였다.

**펜촉 좌표의 흔들림**

카메라에서 검출한 위치는 프레임마다 오차가 발생할 수 있으므로 칼만 필터를 이용한 좌표 보정 과정을 추가하였다.

**손가락 동작 구분**

펜을 잡은 상태에서 엄지의 각도가 달라질 수 있으므로, 기본 그리기와 지우기 동작에서는 엄지를 제외한 네 손가락의 상태를 기준으로 판정하도록 설계하였다.

### 5.2. AI 활용 및 구현 범위

AI의 주요 활용 범위는 펜촉을 탐지하는 파트와 메모장 그리는 파트, 코드 가독성을 높이기 위한 정리, README 초안 작성에 활용되었다.

### 5.3. 추가 참고 사항

현재 프로그램은 파란색 펜과 정해진 손동작을 기준으로 동작하며, 조명과 카메라 각도에 따라 검출 정확도가 달라질 수 있어 조정하여 동작이 필요하다.
